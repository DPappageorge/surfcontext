# surfcontext.org

The official documentation site for **SurfContext** -- the open standard for AI-readable project documentation (ARDS v3.0).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
